# Weather API Integration

A responsive weather application built using HTML, CSS, and JavaScript that retrieves real-time weather information through API integration.

## About the Project

This project demonstrates the integration of an external weather API into a web application. Users can enter a city name to retrieve and view current weather information, including temperature, weather conditions, and weather icons.

The application uses JavaScript Fetch API to send HTTP requests, process JSON responses, and dynamically update the webpage using DOM manipulation.

## Technologies Used

- **HTML5** – Structures the application.
- **CSS3** – Handles styling, layout, and responsive design.
- **JavaScript** – Manages API requests, data processing, and dynamic UI updates.
- **Weather API** – Provides real-time weather information.

## Features

- Search weather information by city name.
- Retrieve current weather data through API integration.
- Display temperature and weather conditions.
- Dynamic weather icons.
- Responsive user interface.
- Error handling for invalid city names and unsuccessful requests.



## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Configure the required weather API key if applicable.
4. Open `index.html` in a web browser.
5. Enter a city name to view its weather information.
